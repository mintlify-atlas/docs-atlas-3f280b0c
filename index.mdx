ZPan gives your S3-compatible bucket a clean web UI, public sharing, image hosting, WebDAV access, and team workspaces — without proxying file bytes through your server. Files transfer directly between the browser and object storage via presigned URLs. The server handles auth, metadata, quotas, and admin operations only.

## Get Started

<Steps>
  <Step title="Choose a deployment target">
    ZPan runs on Cloudflare Workers (recommended — no VPS needed), Docker, AWS Lambda, Vercel, Netlify, or Google Cloud Run. Pick the one that fits your infrastructure.
  </Step>
  <Step title="Deploy and register">
    Follow the deployment guide for your chosen target. The first registered user automatically receives the admin role.
  </Step>
  <Step title="Add your S3 bucket">
    In **Admin → Storage**, configure your S3-compatible bucket (Cloudflare R2, AWS S3, Backblaze B2, MinIO, etc.). The endpoint must be accessible from the client browser since uploads go directly to S3.
  </Step>
  <Step title="Start using ZPan">
    Upload files, create share links, configure image hosting, enable WebDAV, and invite team members — all from the web UI or via the REST API.
  </Step>
</Steps>

<Note>
  ZPan uploads files **directly from your browser to S3** using presigned URLs. The ZPan server never handles file bytes, keeping server bandwidth costs at zero regardless of file size or transfer volume.
</Note>
